# GRFolres GRTeclyn tests

doctest-based tests for the modified-gravity source in `../Source`, built on top
of the GRTeclyn test framework. They mirror the layout of
`GRTeclyn/Tests/` (see that directory's `README.md` for the general doctest
conventions).

## Building and running

Needs sibling checkouts of GRTeclyn and AMReX:

```
codes/
├── amrex/
├── GRTeclyn/
└── GRFolres/        (grteclyn branch)
```

```bash
cd GRFolres/GRTeclyn/Tests
make -j                       # builds Tests<dim>.<config>.ex
./Tests3d.gnu.ex              # run all tests
./Tests3d.gnu.ex -dt-tc="FourDerivScalarTensor"
```

Override paths with `GRTECLYN_HOME`, `AMREX_HOME`, `GRFOLRES_HOME` if the
checkouts are not siblings.

## Tests

### `FourDerivScalarTensorTest`

Port of `GRChombo/Tests/FourDerivScalarTensorTest`. Evaluates the full
modified-CCZ4 + 4dST right-hand side (`ModifiedCCZ4RHS` split kernels +
`ModifiedPunctureGauge`) on a fixed polynomial grid and compares one interior
cell against reference numbers in `FourDerivScalarTensorTest/values1.hpp`.

The reference numbers are generated by
`GRChombo/Tests/FourDerivScalarTensorGridTest`, which runs GRChombo's
`ModifiedCCZ4RHS::compute` on the identical grid, parameters and constant
coupling. See `values1.hpp` for the regeneration steps. Until it is filled in,
the test only checks that the RHS contains no NaNs.
